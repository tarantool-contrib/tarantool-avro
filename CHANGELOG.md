# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

The module was developed inside [pregel](https://github.com/tarantool-contrib/pregel)
as `pregel.avro` and `pregel.compress`, and moved here with its history.

### Added

- `avro`: a self-contained pure-Lua Apache Avro implementation.
- `avro.schema`: schema parsing from JSON text or a Lua table, validation, the Parsing Canonical Form, `tojson()`, and CRC-64-AVRO fingerprints.
- `avro.codec`: binary encoding and decoding of every Avro type, plus `skip` for walking past a value without building it.
- `avro.ocf`: object container file reader and writer with the `null`, `deflate` and `zstandard` codecs, and `read_all`/`write_all`/`schema_of` shorthands.
- `avro.resolve`: schema resolution between a writer and a reader schema, with resolvers cached per pair.
- `avro.deflate`: a pure-Lua RFC 1951 inflater, so a `deflate` container file is readable on any build.
- `avro.compress`: Tarantool Enterprise's `compress` module where there is one, and an FFI binding to the system libz, libzstd and liblz4 where there is not, with the same API and the same bytes. `window_bits` is honoured in both directions.
- `avro.codec_available(name)`, returning the implementation behind a codec as a second value.
- `AVRO_PURE_LUA=1` and `avro.deflate.force_pure` select the pure-Lua inflater; `AVRO_COMPRESS_LIBDIR` names an extra directory to look for the compression libraries in.
- Reference fixtures generated by fastavro 1.12.2, and cross-implementation tests that compare bytes in both directions.

### Changed

- Relative to `pregel.avro`: the modules are `avro.*` and `avro.compress.*`, and the environment variables `PREGEL_AVRO_PURE_LUA` and `PREGEL_COMPRESS_LIBDIR` are now `AVRO_PURE_LUA` and `AVRO_COMPRESS_LIBDIR`.
